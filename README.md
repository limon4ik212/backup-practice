## Назначение файлов

| Файл | Назначение |
|---|---|
| `make_test_data.py` | создаёт тестовые данные отделов в папке `company_data/` (3 отдела × 5 CSV-файлов) |
| `backup.py` | создаёт архив `.tar.gz` с манифестом контрольных сумм SHA-256, удаляет старые копии (ротация), проверяет восстановление, выводит отчёт о различиях и восстанавливает данные |
| `rpo_rto.md` | расчёт RPO и RTO для организации по варианту (задание 5) |

## Команды запуска

Нужен Python 3.12 или новее. Используются только стандартные модули.

```bash
python make_test_data.py      # создать тестовые данные
python backup.py              # создать копию, ротация, проверка восстановления
python backup.py verify       # проверить последнюю копию (отчёт о различиях)
python backup.py restore      # восстановить company_data из последней копии
```
